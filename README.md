# FFL — version propre

Ce ZIP est un site FFL indépendant. Il ne contient pas l'ancien code FYFL/Halloween.

Variables Vercel : SUPABASE_URL, SUPABASE_PUBLISHABLE_KEY, SUPABASE_SERVICE_ROLE_KEY, ADMIN_PASSWORD.

1. Extraire le ZIP et envoyer les fichiers à la racine GitHub.
2. Exécuter supabase.sql une fois dans Supabase SQL Editor.
3. Ajouter les 4 variables dans Vercel (Production/Preview/Development si souhaité).
4. Redeploy.
